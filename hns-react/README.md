# HNS — интернет-магазин на React

Модернизированная версия интернет-магазина цифровой техники, перенесённая на фреймворк React со сборщиком Vite.

## Технологии

- React 19
- Vite 8
- React Context API (глобальное состояние: корзина, избранное, уведомления)
- localStorage (сохранение данных между сеансами)

## Функциональность

- Главная страница со сплэш-анимацией, баннером и навигацией
- Каталог товаров с фильтрами по категориям и поиском
- Страница товара с характеристиками
- Страница «Поддержка» с FAQ-аккордеоном
- Корзина и избранное с сохранением в браузере

## Запуск

```bash
npm install   # установить зависимости
npm run dev   # запустить dev-сервер
npm run build # production-сборка
```

## Структура

- `src/data.jsx` — данные о товарах
- `src/store.jsx` — глобальное состояние (Context)
- `src/components/` — переиспользуемые компоненты
- `src/pages/` — страницы
- `src/App.jsx` — корневой компонент и маршрутизация
- `public/img/` — статические изображения
